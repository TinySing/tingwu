使用说明

工作流程：

  1. DeepSeek 根据你的需求生成提示词
  2. 提交到听悟重跑，用真实转写文本执行
  3. 等待听悟返回实际输出结果
  4. DeepSeek 评估输出是否满足期望
  5. 不满足则自动优化；完成后仍可追问继续改

前提条件：

  • 源 TaskId 对应的任务必须已完成
  • 配置中心已填写 DeepSeek API Key
  • 每轮迭代约需 30-60 秒（含听悟处理时间）
